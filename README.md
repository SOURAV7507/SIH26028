# SIH26027
AI-powered railway maintenance block optimizer for coordinated scheduling, reduced downtime, and maximum asset availability.



. 🚆 Project Title

AI-Powered Automatic Block Planning for Indian Railways


📌 Problem Statement

Explain the current problem:

Engineering, OHE/Traction and Signalling maintenance are planned separately.
Maintenance information is distributed across different systems.
Manual/decentralized planning can cause inefficient block utilization.
Maintenance blocks can conflict with train operations.
Asset downtime can increase.


🏗️ System Architecture
TMS / SMMS / TDMS
        ↓
Data Integration
        ↓
Maintenance Priority Engine
        ↓
Train Schedule + Corridor Availability
        ↓
AI/Optimization Engine
        ↓
Conflict Detection
        ↓
Optimized Block Plan
        ↓
Dashboard + Analytics
